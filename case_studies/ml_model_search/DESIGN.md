# Case study 5 (design, pre-registered before any results): How many ML-discovered return predictors survive?

**Status:** design only, written 2026-09-13. No data has been fitted. The grid, metrics and pass rules below are
fixed now so that nothing can be tuned after seeing results. Changes after this point must be logged in the
"Amendments" section with a date and a reason.

## Question
When a researcher searches over many machine-learning models to predict returns, how many apparent out-of-sample
winners are false discoveries? And do standard corrections still work when the candidates are generated by the
search itself and are highly correlated with one another?

## Why it matters
Classical tools for the best-of-many problem (White's Reality Check, Hansen's SPA, Romano–Wolf stepdown, Harvey–Liu–Zhu
style haircuts, Benjamini–Hochberg FDR) assume a fixed, pre-specified candidate set. ML search produces large,
adaptive, near-collinear candidate sets. This study measures how far that gap matters in practice.

## Data (free, already used in these repos)
- Daily S&P 500, NASDAQ and WTI from the `arch` package (as in dc-ml-trading).
- Extension only after the daily study is complete: intraday data from the crypto order-flow recorder.

## The candidate search (fixed grid)
| Dimension | Levels |
|---|---|
| Model | ridge, lasso, gradient boosting, random forest, small MLP (1 hidden layer) |
| Feature set | lagged returns only · lagged returns + realised volatility · lagged returns + volatility + volume |
| Lookback window | 5, 10, 20, 60 days |
| Forecast horizon | 1, 5 days |
| Key hyperparameter | 3 levels per model |
Total candidates N = 5 × 3 × 4 × 2 × 3 = **360 per asset, 1,080 overall**.
Each candidate is fitted walk-forward (expanding window, refit monthly) and traded as sign(prediction) with a fixed
round-trip cost. Output: a T × N matrix of out-of-sample daily strategy returns.

## Two worlds
1. **Real data.**
2. **Known-null world.** The same search run on data whose predictive link is destroyed (block-permuted returns,
   preserving volatility clustering). Every "winner" here is false by construction, so this world measures how often
   each method is fooled under the same correlation structure.

## Measures (fixed)
For each world and asset:
- nominal winners: out-of-sample Sharpe t-stat > 2
- survivors of the Deflated Sharpe Ratio (N = nominal count and N = effective count)
- Probability of Backtest Overfitting (CSCV, 16 splits)
- Romano–Wolf stepdown with stationary block bootstrap, familywise 5%
- Hansen SPA test against a zero-return benchmark
- Benjamini–Hochberg at 10% FDR on bootstrap p-values
- effective number of independent trials from the eigenvalues of the candidate return correlation matrix

## Pre-registered reading
- In the known-null world, a method "controls error" if it declares at most 5% false winners (familywise methods)
  or keeps the realised FDR at or below 10% (BH).
- The headline number is the ratio of nominal candidates to effective independent trials. It quantifies how much
  classical corrections over- or under-correct.
- A finding that the corrections work well is a valid result and will be reported as such.
